# Bursal Consulting & Management — Website

Responsive website for Bursal Consulting & Management, a DBE/WBE-certified construction management firm offering project management, cost estimating, risk assessment and scheduling.

**Live:** https://www.bursalconsulting.com

## What I did

- Designed and built the site: projects portfolio, services, clientele and contact pages
- Showcased the firm's transit and infrastructure work so prospective clients see relevant experience fast
- Fully responsive, from phone to desktop

## Stack

Next.js · TypeScript · Firebase (Firestore) · Vercel
